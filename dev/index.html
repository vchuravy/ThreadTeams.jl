ThreadTeams.jl

A team of persistent worker tasks, one per thread, that runs OhMyThreads.jl's parallel functions with low per-loop overhead. The package re-exports the OhMyThreads.jl API (tforeach, tmapreduce, tmap, @tasks, ...) and adds two schedulers that run on the team, TeamScheduler (:team) and GreedyTeamScheduler (:greedyteam).

One sticky worker task runs per thread of the :default thread pool. A parallel loop splits its range into one contiguous chunk per thread, runs chunk 1 on the calling task and hands the rest to the workers. After a loop, idle workers spin (100 µs by default) before they sleep, so back-to-back loops do not pay for creating, scheduling and waking tasks. Starting a loop costs about 0.3 µs and allocates nothing after its first run, against 2–4 µs and about 3 KB for Threads.@threads or OhMyThreads' default scheduler (see Overhead).

Installation

The package is not registered yet:

pkg> add https://github.com/vchuravy/ThreadTeams.jl

It needs Julia 1.10 or newer, OhMyThreads.jl 0.8.7 and ChunkSplitters.jl; the Enzyme rules load with EnzymeCore.jl.

Usage

using ThreadTeams   # re-exports OhMyThreads.jl; start Julia with threads, e.g. `julia -t auto`

x = rand(10_000)
y = similar(x)

const team = TeamScheduler()
tforeach(eachindex(x); scheduler = team) do i
    y[i] = sqrt(x[i])
end
tmapreduce(abs2, +, x; scheduler = team)                         # parallel mapreduce
tmap(sqrt, x; scheduler = GreedyTeamScheduler(chunksize = 256))  # load balancing
@tasks for i in eachindex(x)
    @set scheduler = team
    y[i] = 2x[i]
end
s, m = @tasks for i in eachindex(x)                                 # reductions
    @set scheduler = team
    @set reducer = (a, b) -> (a[1] + b[1], max(a[2], b[2]))
    (x[i], x[i])
end

Pass the scheduler as an object: OhMyThreads resolves a symbol (scheduler = :team) with a dynamic dispatch, about 0.3 µs and 64 bytes per loop.

When to use it

  • Use it for many small to medium parallel loops in a row, where the per-loop overhead of Threads.@threads (2–4 µs, or about 100 µs with oversubscription) is a noticeable part of the run time. A typical case is the right-hand side of a PDE solver: 10–20 loops of a few µs each per call.
  • Use OhMyThreads' own schedulers (DynamicScheduler, the default) for large loops, where a few µs per loop do not matter, for loop bodies that are unbalanced beyond what GreedyTeamScheduler handles or that yield (I/O, locks, wait), and for composable task-based parallelism or @barrier. Switching is one keyword argument.

With Enzyme.jl loaded, operations on the team can be differentiated in forward and reverse mode.

See Design for the semantics of the team (chunking, stealing, serial fallback, exceptions, dynamic scope, reductions), Overhead for measurements, and Trade-offs and caveats for CPU use while idle, hybrid CPUs, automatic differentiation and captured variables.
